# Лабораторные по A* — Дергачёв

Учебные лабораторные по алгоритму A*: реализация поиска и сравнение эвристик на картах.

**Обе лабораторные выполнены.** В репозитории сохранены решения, данные, результаты экспериментов и выводы.

## Лабораторная 3 — A*

[Ноутбук с решением](lab03-astar/lab03_astar.ipynb)

Реализованы:

- A* на 4-связной сетке;
- структуры OPEN и CLOSED на основе очереди с приоритетом и словаря;
- поиск с повторным открытием вершин для несогласованной эвристики;
- восстановление и визуализация маршрута;
- два tie-break: предпочтение большего и меньшего `g` при одинаковом `f`;
- проверки корректности и сравнение числа шагов поиска и размера дерева.

Карты находятся в `lab03-astar/data/`, иллюстрации — в `lab03-astar/img/`.

## Лабораторная 4 — сравнение эвристик A*

[Ноутбук с экспериментами](lab04-benchmarking-astar/lab04_benchmarking_astar.ipynb) · [Описание эксперимента и выводы](lab04-benchmarking-astar/lab04_conclusions.md) · [Исходное задание](lab04-benchmarking-astar/README.md)

Реализован поиск на 8-связной сетке без срезания углов: прямой шаг стоит 1, диагональный — √2. Сравниваются эвристики Евклида, Octile, Чебышёва и Манхэттена с фиксированным tie-break `g_max`.

Эксперимент выполнен на трёх картах MovingAI из разных коллекций: `arena`, `ht_chantry` и `AR0021SR`. На каждой карте использовано 100 задач, одинаковых для всех эвристик, — всего **1200 измеряемых запусков**.

Для каждой версии сохранены успешность нахождения кратчайшего пути, число раскрытий и время поиска. Результаты представлены таблицами и графиками со средними значениями, медианами и показателями разброса. Описание методики и анализ результатов включены в ноутбук.
