## Лабораторная 3 — A*

Папка `lab03-astar/`:
- `lab03_astar.ipynb` — исходный ноутбук с условиями и заготовками;

- `img/` — иллюстрации из задания.

## Лабораторная 4 — сравнение A*

Папка `lab04-benchmarking-astar/`:
- `README.md` — исходные требования.

Готового ноутбука в задании нет. Понадобятся поиск на 8-связной сетке без срезания углов, четыре эвристики, минимум три карты MovingAI и сто задач на каждую карту, замеры и анализ результатов.
